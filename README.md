### 03. AI-Based Industrial Conveyor Foreign Material & Anomaly Detection System

An AI-powered computer vision application designed to identify unwanted foreign materials in industrial conveyor raw material streams using a custom-trained YOLO object detection model.

The system provides ROI-based monitoring, foreign material detection, object tracking and live video analytics.

**Key Features:**
- Custom YOLO-Based Foreign Material Detection.
- Interactive Region of Interest (ROI) Selection.
- Real-Time Video Detection and Monitoring.
- ByteTrack-Based Object Tracking.
- Current Detection and Cumulative Object Counts.
- Automated Analytics Video Generation.
- Output Video Management with a Maximum of 6 Videos.

**Project Modules:**
- Dataset Preparation and Image Annotation.
- Custom YOLO Model Training and Testing.
- Foreign Material Detection and Tracking.
- ROI-Based Conveyor Monitoring.
- Live Video Analytics and Detection Visualization.
- Processed Video Output and Result Screenshots.

**Key Technologies:** Python, OpenCV, PyTorch, Ultralytics YOLO, ByteTrack, Computer Vision.
