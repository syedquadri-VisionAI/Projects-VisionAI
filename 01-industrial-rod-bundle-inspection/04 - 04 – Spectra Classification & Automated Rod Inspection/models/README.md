

# Trained Model Weights

This application requires three trained YOLO models.

| Model | Function |
|---|---|
| bundle_best.pt | Bundle detection and tracking |
| rod_best.pt | Individual rod detection |
| spectra_classifier_best.pt | Three-class rod-face classification |

Place the trained model weights in this directory before running the application.

Note: Model weights are excluded from GitHub because of their file size.
