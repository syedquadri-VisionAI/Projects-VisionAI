# 02 – YOLO Model Training & Testing

## Overview

This module covers the training, validation and testing of two independent YOLO object detection models developed for industrial steel rod and bundle inspection.

Both models use custom-prepared and manually annotated datasets from Module 01.

## Models Developed

### 1. Rod Detection Model

- Architecture: YOLO object detection
- Task: Individual steel rod detection
- Number of classes: 1
- Class name: `rod`
- Class ID: `0`

### 2. Bundle Detection Model

- Architecture: YOLO object detection
- Task: Complete rod bundle detection
- Number of classes: 1
- Class name: `bundle`
- Class ID: `0`

The models are trained independently using their respective datasets.

## Development Workflow

1. Prepare YOLO-compatible datasets.
2. Configure dataset paths and class names.
3. Load pretrained YOLO weights.
4. Configure training parameters.
5. Train the rod and bundle models independently.
6. Validate training performance.
7. Test models using images and videos.
8. Review detection outputs and model performance.

## Model Evaluation

Training and validation results are documented using the metrics and visualizations generated by the actual training runs.

Evaluation may include:

- Precision
- Recall
- mAP@50
- mAP@50–95
- Confusion matrix
- Precision–Recall curve
- F1 curve

## Testing

Both models are evaluated independently on sample images and video footage.

Detection results are reviewed using bounding boxes, class labels and confidence scores.

## Model Outputs

The trained model checkpoints are saved separately for rod and bundle detection.

The best-performing checkpoint is generally saved as `best.pt`, while `last.pt` represents the final training epoch.

## Limitations

Detection performance depends on dataset quality, image variation, object visibility, camera angle and training configuration.

The models require further validation on representative industrial footage before production deployment.
